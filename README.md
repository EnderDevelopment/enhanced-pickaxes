# Enhanced Pickaxes

Enhanced Pickaxes is a Minecraft plugin that adds custom crafting recipes and textures for copper, iron, diamond, and netherite pickaxes. This plugin enhances the vanilla Minecraft experience by providing new tools with unique visuals and crafting methods.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Craft the custom pickaxes using the new recipes:
   - **Copper Pickaxe**: 3 copper ingots and 2 sticks.
   - **Iron Pickaxe**: 3 iron ingots and 2 sticks.
   - **Diamond Pickaxe**: 3 diamonds and 2 sticks.
   - **Netherite Pickaxe**: 3 netherite ingots and 2 sticks.
2. Use the custom pickaxes to mine blocks with enhanced efficiency.
